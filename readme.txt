== Frequently Asked Questions ==

= How do I remove /pageforge/ from newly generated Page URLs? =

Edit the template and set Target Post Type to Page, or choose Use global default and set Settings > Default Post Type to Page. Native Pages appear under Pages > All Pages and use WordPress Page permalinks. Existing template-specific choices override the global default; changing a default does not convert existing content.

= What does Generated CPT Slug Base change? =

This existing setting changes the nonempty prefix for PageForge custom content, for example /pageforge/the-magnolias/ to /locations/the-magnolias/. It does not select the output post type or provide a root-level custom post type. Save the setting to refresh rewrite rules. Native Pages use WordPress Page permalinks independently of this setting. Changing an established base affects published links; arrange redirects from old URLs separately. PageForge does not create redirects automatically.

= Can Free generate child Pages under a parent? =

Yes. Set the template target to Page and select one existing Parent Page, or None for a root Page. For example, a maths-tuition-gurgaon parent and dlf-phase-iv child use /maths-tuition-gurgaon/dlf-phase-iv/ with pretty permalinks enabled. Base Layout to Clone only supplies layout/content; it is separate from Parent Page. Invalid or inaccessible parents stop generation. Existing Pages are not moved automatically.

= Can a different parent be selected for every CSV row? =

Automatic Parent ID or Parent Path column mapping requires licensed PageForge Premium (Starter or higher). Free includes one static parent per template. Google Sheets remains available on Premium Professional and Enterprise. All referenced parents must exist before the run; forward references and automatic tree creation are not supported.

== External Services ==

PageForge can connect to optional third-party services when you explicitly configure and use them.


= External services and privacy =

External integrations remain inactive until an authorised WordPress user configures the required connection and uses a feature that requires it.

When an AI feature is used, the prompt and the content or settings required to complete that request are sent to the selected provider.

Processing is governed by that provider's own terms, privacy policy, API limits, billing, retention policies, and regional availability.

= PageForge MCP remote connections =

* **Service:** Model Context Protocol connection between your WordPress site and an AI/MCP client you choose to configure.
* **Use:** Allows an explicitly authorised MCP-compatible client to access controlled PageForge tools.
* **Data Sent:** Only information requested through a permitted PageForge MCP tool and allowed by the connected WordPress user's permissions and MCP scopes.
* **Authentication:** OAuth-based remote connections or Personal Access Tokens depending on the client.
* **Default State:** MCP is disabled until an authorised WordPress user enables it.
* **Free Behaviour:** PageForge Free MCP exposes read, analysis, validation, preview, and dry-run capabilities only.

The third-party AI/MCP client you connect may separately process information returned by PageForge according to that client's own terms and privacy policy.


== Privacy ==

PageForge does not send data to PageForge or Codefreex servers during normal Free CSV generation.

External requests are only made to services or clients you explicitly configure and use.

If you configure an AI provider, relevant prompts and context may be sent to that provider.

If you configure Pexels, search terms may be sent to Pexels.

If you configure Google Analytics, event information may be sent to your GA4 property.

If you enable and authorize MCP, PageForge can return permitted WordPress/PageForge information to the MCP client you explicitly connect.

MCP is disabled by default.

PageForge Free MCP does not register live-write tools.
